# Bellabeat Smart Device Usage Analysis
### Google Data Analytics Certificate — Capstone Project

## Overview
Analysis of FitBit fitness tracker data from 35 users to identify 
smart device usage trends and generate data-driven marketing 
recommendations for Bellabeat — a high-tech wellness company for women.

## Tools Used
- **Google Sheets** — Data cleaning and preparation
- **BigQuery SQL** — Data analysis and querying
- **Python (Pandas)** — Statistical analysis and correlation
- **Tableau** — Data visualization and dashboard

## Key Findings
1. 34% of users are sedentary — the largest single activity segment
2. Only 49% of users wear their device consistently every day
3. Sedentary time shows a -0.59 negative correlation with sleep duration
4. Peak activity occurs at 7PM — after work exercise is primary activity
5. Saturday is most active day; Sunday is least active

## Top Recommendations
1. **Improve device design appeal** — discreet, aesthetic designs drive consistent wear
2. **Target sedentary users with sleep messaging** — "Move more, sleep better"
3. **Leverage peak activity timing** — smart notifications at 5-6PM weekdays
